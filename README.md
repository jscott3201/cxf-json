# modelica-json-rust

Private Rust project for a purpose-built CXF parser and validator, with planned
Python and WebAssembly adapters. JSON-LD and RDF processing are internal CXF
ingestion details, not general-purpose APIs. The current code is an internal
probe; it does not implement CXF projection or validation and must not process
untrusted input.

Development is private and pre-release. A future public release will be
available under either the MIT License or Apache License 2.0 after the project's
stability gate is met.
