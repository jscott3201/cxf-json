## Behavioral findings

### Serde boundary

- `serde_json` retains neither duplicate-member multiplicity nor number spelling
  in `Value`. The observed duplicate fixture is last-wins, and `1e+02` becomes a
  semantic value equal to 100.
- `SourceDocument` retains the exact accepted bytes, including original number
  spelling and object-member order.
- Malformed JSON and invalid UTF-8 return an owned source plus structured JSON
  diagnostic. Serde error line/column is converted to a zero-based position.
- Owned source, diagnostics, and RDF summaries round-trip through `serde_json`.
- The Serde-only feature set builds and runs without Oxigraph.

These results support D-014: v1 retains input bytes and parser error positions
without claiming successful-node spans or byte-for-byte reserialization.

### OxJSONLD boundary

- Embedded contexts produce the expected named subject, predicates, named-node
  object, string and integer datatypes, language tag, unknown predicate, and
  default graph placement.
- A graph object retains its named graph IRI.
- A remote `@context` fails deterministically because no load callback or
  network-capable dependency is installed.
- Underlying JSON syntax failures retain OxJSONLD's byte offset and zero-based
  line/column range; JSON-LD processing failures may have no source range.
- The adapter and its dependencies compile for `wasm32-unknown-unknown` with the
  D-016 target-only `getrandom` exception.

The Serde-only WASM build excludes `getrandom` and `wasm-bindgen`; D-016 is tied
to the `oxigraph` feature.

These results qualify OxJSONLD for W-003 evaluation. They do not establish W3C
JSON-LD conformance or CXF compatibility.
