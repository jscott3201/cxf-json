## Existing repository evidence

The nine checked-in JSON/JSON-LD fixtures were authored for this repository.
`crates/cxf-ingest-probe/tests/fixtures/PROVENANCE.md` records their project
license and non-derivation statement. W-024 and W-003 record SHA-256 values.
Invalid UTF-8 and additional negative cases are assembled in Rust tests rather
than copied as fixture files.

W-003 and W-004 qualified two local external roots at Open Control commit
`aa7bbae…`. W-005 reconfirmed both through hardened Git-object mode:

| Rights bucket | Files | Passed | Classified failures | Bytes | Object-mode elapsed |
|---|---:|---:|---:|---:|---:|
| Open Control fixture tree | 162 | 161 | 1 | 2,514,450 | 713,361 us |
| Generated Buildings CXF | 44 | 44 | 0 | 2,114,507 | 249,303 us |

W-005 hardens Git-backed mode to read exact blobs from the approved commit object
database. Worktree changes and concurrent path swaps cannot alter parsed bytes.
The harness no longer runs `git status`, avoiding worktree filters from local Git
configuration. Commit-tree membership prevents index changes from omitting
approved files, and tree-mode checks reject symlink payloads. The harness requires
the actual repository top level and Git 2.45 or newer. It disables lazy object
fetch, hooks, and other optional Git execution paths. Exact expected messages are
matched only in memory; source-derived parse and read diagnostics are redacted.
W-005 did not modify or execute the external checkout.

## Operational result

- Current CI and Node/WASM smoke tests use only repository-authored fixtures.
- No HTTP, filesystem loader, or fixture downloader is added.
- The external harness requires explicit local paths and has no fetch operation.
- Reports contain aggregate compatibility results, not fixture payloads or
  external diagnostic content.
- No fixture-specific third-party notice is added because no external fixture
  byte is distributed. W-021 still owns dependency and artifact notice review.

This policy preserves a reproducible default test suite while keeping external
compatibility evidence available to operators who separately acquire the pinned
checkout.
